# ⚡ Twilio Phone Number Setup - Quick Reference Card

## 3️⃣ Things You Need

| # | What | Where to Find | Format | Example |
|---|------|---------------|--------|---------|
| 1️⃣ | **Account SID** | Twilio Console → Settings → General | ACxxxx... | ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx |
| 2️⃣ | **Auth Token** | Twilio Console → Settings → General (click SHOW) | xxxx... | your_auth_token_here |
| 3️⃣ | **Phone Number** | Twilio Console → Phone Numbers → Active Numbers | +XXXXXXXXX | +12125551234 |

---

## 🚀 5-Minute Setup

### 1. Create Twilio Account (2 min)
```
Go to: https://www.twilio.com/console
Sign up → Verify phone → Done!
```

### 2. Copy Your 3 Values (2 min)
```
Settings → General:
  • Copy Account SID: ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  • Copy Auth Token: (click SHOW, then copy)
  
Phone Numbers → Active Numbers:
  • Copy Phone Number: +1234567890
```

### 3. Set Environment Variables (1 min)
**Windows PowerShell:**
```powershell
$env:TWILIO_ACCOUNT_SID = "ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
$env:TWILIO_AUTH_TOKEN = "your_auth_token_here"
$env:TWILIO_PHONE_NUMBER = "+1234567890"
```

**Linux/Mac:**
```bash
export TWILIO_ACCOUNT_SID="ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
export TWILIO_AUTH_TOKEN="your_auth_token_here"
export TWILIO_PHONE_NUMBER="+1234567890"
```

## ⚠️ Common Mistakes

| ❌ Mistake | ✅ Fix |
|-----------|--------|
| "SMS NOT CONFIGURED" error | Set environment variables BEFORE starting app |
| Auth Token not working | Click [SHOW] in Twilio Console, copy exact value |
| Phone number format wrong | Must be: +countrycode (e.g., +12125551234) |
| Env var not recognized | Restart terminal/IDE after setting |
| SMS fails silently | Check Twilio account balance/trial credits |

## 📞 Phone Number Format

### ✅ Correct
```
+1234567890
+12125551234
+441234567890
+919876543210
```

### ❌ Wrong
```
1234567890 (no + or country code)
(212) 555-1234 (has parentheses)
212-555-1234 (has dashes)
```

## 🆘 Quick Troubleshooting

| Issue | Solution |
|-------|----------|
